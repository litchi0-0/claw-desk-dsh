# 桌宠点击回应

## 问题与计划

原版 Clawd 1.4.0 单击只显示任务信息，双击或四连击才播放动画。动画版此前也会用完整点播保护拦住点击回应。

本次计划并完成：补上单击动作、复用完整播放调度、验证连续点击与拖拽优先级、更新本机应用并提交。

## 使用方法

- 待机时单击身体左半边：挥手（wave.webp）。
- 待机时单击身体右半边：害羞（shy.webp）。
- 约 0.4 秒内连续点击：保留原有双击和四连击特殊回应。
- 右键仍打开分层动画菜单。

单击等待 400 毫秒以判断连续点击。回应使用主题配置的完整时长，当前两段均约 10.04 秒，从素材加载完成后计时。点击回应可替换右键点播，期间普通状态更新不会截断；拖拽可以立即接管。播放结束恢复最新工作状态。

保留原有约束：正在工作、免打扰、其他点击回应正在播放时不触发新点击回应；迷你模式单击用于退出。无工作待机计时规则保持不变。

## 实现与验证

`scripts/patch-clawd-click.py` 对原版点击处理器做唯一匹配补丁；安装脚本把点击 IPC 接到完整点播播放器。保留拖拽检测、快捷键和多击累积逻辑。

运行 `node --test tests/clawd-*.test.cjs`，共 20 项通过，包括原版缺失单击复现、左右动作选择、四连击不重复触发、免打扰、完整播放路由、拖拽和按工作待机回归。无原版 macOS 应用时跳过依赖 ASAR 的一项构建集成检查。

本机动画版已更新并重新启动，原版应用保留。上一个动画版备份位于 `~/Library/Application Support/clawd-on-desk/app-backups/click-20261029-135300/`。运行时完整视觉播放仍需人工观察确认。
