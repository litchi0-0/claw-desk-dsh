## 使用方法

入口为 **右键 → 播放动画 → 扩展素材**：

- **大肥鱼表情（静态）**：24 张表情按中文名称列出，选择后在头顶显示约 6 秒，然后收起。不是动画，不加入自动待机池，不替换工作画面。
- **音效试听**：可分别试听桌面版轻点、小鸭 Ya1／Ya2、任务开始／完成／出错。
- **点击声音**：在现有原版嘎嘎、桌面版轻点、小鸭 Ya1、小鸭 Ya2 中选择，立即试听并保存，下次启动仍保留。Ya1／Ya2 是可选触碰声音，没有绑定成“余额档位配音”。
- **屏幕碰撞音效**：默认关闭，开启后使用当前点击声音；真实反弹反馈才触发，180 ms 节流。
- **任务提示音（开始／完成／出错）**：默认关闭。开启后根据真实会话状态变化触发；初始化不补播，持续工作不反复播放，并接管原完成提示音，避免两声重叠。关闭时不为该功能构造会话快照，开启时最多每 500 ms 检查一次；原权限确认提示保持原用途。

所有音效沿用应用主音量的 50%，尊重全局静音与免打扰。点击声仍尊重主题点击音开关和 100 ms 连点节流。图片窗口不抢焦点、鼠标穿透、限制在显示器工作区；图片显示不受音频静音影响。

偏好保存于用户数据目录 `clawd-extra-media-prefs.json`，只包含声音选择及两个开关，不包含 API Key 或会话内容。图片与音效随 ASAR 离线分发；运行时不访问参考仓库。`extraMedia: false` 可禁用本次扩展入口。

普通工作气泡继续保持关闭，71 项自动动作池不混入静态图、工作提示音或新的随机噪音。余额动画仍按原有 95／80／70／50／25／5 阈值触发。
