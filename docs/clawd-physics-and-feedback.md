# 甩抛物理与更多点击反馈

## 本次范围和计划

用户明确本次碰撞只需要**屏幕边界反弹**，不要求多宠物互撞。主题升级到 1.5.0，补齐拖拽松手后的物理行为，以及已导入却缺少手势的挠痒、受惊素材。

计划并完成：核对原版输入/拖拽/画面恢复链路；实现速度估计、飞行与边界反弹；接入长按、弹弓、Q 弹和音效；执行物理与真实输入处理器回归；更新本机应用、文档和 GitHub。

## 使用方法

| 操作 | 效果 |
| --- | --- |
| 普通拖动、慢慢放下 | 保持原生拖动；没有足够甩动速度时原地放下 |
| 快速拖动后松手 | 根据松手前轨迹获得初速度，抛出后受重力、四边反弹和地面摩擦影响，最终停下 |
| 双击时按住第二下，拖动后松手 | 角色留在原处并产生弹性拉伸，朝拉动的反方向弹出 |
| 飞行时按住角色 | 抓住并停止飞行，可接着普通拖动 |
| 空闲时长按约 700 ms，不拖动 | 播放“挠痒咯咯笑”；松手不再额外触发普通单击 |
| 空闲时 Shift＋单击 | 主动播放“被吓一跳” |
| 空闲时光标从外快速进入角色区域 | 达到速度与位移阈值且被采样捕捉时触发受惊，冷却 5 秒 |
| 普通点击 | 立即短促 Q 弹与轻音效，原来的单击/双击/四连击动画保留 |

弹弓需要第二次按下发生在上一次松手后的 400 ms 内；第二下没有拖动就仍然走原来的多击回应。Cmd/Ctrl 快捷键与右键菜单保持原用途。失焦、pointercancel、强制释放只取消手势，不把中断误判为甩抛。

**AI 正在工作、免打扰、迷你模式、权限气泡或菜单阻塞时不启动飞行。** 飞行中出现工作或其他阻塞也会停止，恢复最新工作画面；不会为了演示物理而改变实际任务状态。挠痒和受惊动画同样在 AI 空闲时触发。普通点击的轻 Q 弹属于直接触碰反馈，不会修改工作状态。

## 物理和显示

- 初速度来自最近 150 ms 的指针轨迹；停顿放下、跨度过短或速度不足不抛。默认甩抛死区 320 px/s，上限 2400 px/s。
- 弹弓的初速与拉伸距离成比例并反向，上限同上；拉伸不足 12 px 不弹出。
- 默认重力 1400 px/s²，反弹速度保留约 68%，地面水平摩擦逐渐衰减；单步时间限制到 32 ms，避免系统卡顿后大跳。
- 以角色可见身体的命中矩形贴当前显示器工作区四边来反弹，不以透明画布边缘提前碰撞。支持负坐标显示器，任务栏/Dock 留在工作区外；本次不模拟跨屏飞行。
- 飞行期间冻结窗口尺寸，每帧同步命中窗口和锚定表面；放开窗口位置协调器保护后才保存位置。15 秒上限防止异常永久飞行。
- 飞行显示悬空素材，普通 idle 恢复请求不能截断；工作、主动抓住、显式点播等有明确的停止路径，过期计时回调不会续飞。
- Q 弹和拉伸使用独立 CSS scale/rotate，不覆盖原来的朝向/移动 transform；撞墙沿碰撞轴挤压，落地沿竖轴挤压。

原生拖拽仍是 Clawd 的跟手拖动，本次没有换成 DSH 的弹簧跟随引擎；碰撞范围按用户选择限定到屏幕四边。

## 点击音效与开关

使用本仓库合成的 65 ms PCM WAV 轻音效，经 Clawd 原有播放链路播放；音量为应用主音量的 35%，尊重全局静音、音量和免打扰。不是下载或复制上游的音频。

主题扩展：

```json
"petInteractions": { "enabled": true, "clickSound": true }
```

`enabled: false` 关闭本次扩展；`clickSound: false` 只关闭轻音效。修改主题后重新安装主题并重启。其他未启用此字段的主题不增加长按/弹弓手势。

## 源码与验证

- `clawd-physics.js`：纯物理步进、边界与速度估计。
- `clawd-physics-runtime.js`：手势/飞行状态、采样、取消和受惊检测。
- `patch-clawd-gestures.py`：原版完整输入处理器的受控补丁。
- `patch-clawd-interactions.py`：输入桥、可信主框架 IPC、飞行显示优先级、窗口同步和反馈接线。
- `clawd-feedback-renderer.js`：Q 弹和弹弓拉伸；不改原动画文件。

66 项 Node 测试通过，包括真实原版 hit-renderer 的长按/多击/失焦/取消路径、飞行取消、四边反弹、静止收敛、窗口尺寸、显示优先级、静音与 IPC 来源限制；此前自动动作、额度与步态同步回归保留。原版输入 fixture 来自 Clawd 1.4.0，遵守 AGPL，致谢见仓库首页。

已构建并更新本机应用，核对安装的输入桥、主题开关、反馈脚本、物理模块和音效文件，签名检查通过。原生界面尝试了长按与拖拽，检查 Dashboard 确认本轮 Codex 会话正在运行，因此飞行按工作优先级被阻止；没有伪造空闲状态。空闲时完整飞行/弹弓时序由模拟时钟测试覆盖，真实手感和扬声器听感未作为已完成的人工验证。

原版应用保留；本次之前的动画版和主题备份于用户数据目录 `app-backups/physics-20261029-153934/`。上游交互设计和物理参数参考 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，现有动画及许可不变。
