# 甩抛物理与更多点击反馈

## 本次范围和计划

用户明确本次碰撞只需要**屏幕边界反弹**，不要求多宠物互撞。主题当前为 1.5.1，补齐拖拽松手后的物理行为，以及已导入却缺少手势的挠痒、受惊素材。

计划并完成：核对原版输入/拖拽/画面恢复链路；实现速度估计、飞行与边界反弹；接入长按、弹弓、Q 弹和音效；执行物理与真实输入处理器回归；更新本机应用、文档和 GitHub。

## 使用方法

| 操作 | 效果 |
| --- | --- |
| 普通拖动、慢慢放下 | 保持原生拖动；没有足够甩动速度时原地放下 |
| 快速拖动后松手 | 根据松手前轨迹获得初速度，抛出后受重力、四边反弹和地面摩擦影响，最终停下 |
| 双击时按住第二下，拖动后松手 | 角色留在原处并产生弹性拉伸，朝拉动的反方向弹出 |
| 飞行时按住角色 | 抓住并停止飞行，可接着普通拖动 |
| 空闲时长按约 700 ms，不拖动 | 播放“挠痒咯咯笑”；松手不再额外触发普通单击 |
| 空闲时 Shift＋单击 | 主动播放“被吓一跳” |
| 空闲时光标从外快速进入角色区域 | 达到速度与位移阈值且被采样捕捉时触发受惊，冷却 5 秒 |
| 普通点击 | 立即短促 Q 弹与轻音效，原来的单击/双击/四连击动画保留 |

弹弓需要第二次按下发生在上一次松手后的 400 ms 内；第二下没有拖动就仍然走原来的多击回应。Cmd/Ctrl 快捷键与右键菜单保持原用途。失焦、pointercancel、强制释放只取消手势，不把中断误判为甩抛。

**主动甩抛在 AI 工作时也可使用。** 工作状态持续正常更新，飞行结束后恢复最新工作画面；甩抛不修改实际任务状态。免打扰、迷你模式、权限气泡、菜单或退出会阻止/停止飞行。挠痒和受惊动画同样在 AI 空闲时触发。普通点击的轻 Q 弹属于直接触碰反馈，不会修改工作状态。

## 物理和显示

- 输入窗口直接记录屏幕坐标，避免跟手窗口的局部坐标抵消位移；通过可信 IPC 传递最多 64 个有限、有序、近期样本。初速度取最后 60 ms 的轨迹，支持至少 8 ms 的短促甩动；停顿放下或速度不足不抛。默认甩抛死区 320 px/s，上限 2400 px/s。
- 弹弓的初速与拉伸距离成比例并反向，上限同上；拉伸不足 12 px 不弹出。
- 默认重力 1400 px/s²，反弹速度保留约 68%，地面水平摩擦逐渐衰减；单步时间限制到 32 ms，避免系统卡顿后大跳。
- 以角色可见身体的命中矩形贴当前显示器工作区四边来反弹，不以透明画布边缘提前碰撞。支持负坐标显示器，任务栏/Dock 留在工作区外；本次不模拟跨屏飞行。
- 飞行期间冻结窗口尺寸，每帧同步命中窗口和锚定表面；放开窗口位置协调器保护后才保存位置。15 秒上限防止异常永久飞行。
- 飞行显示悬空素材，普通 idle 恢复请求不能截断；主动抓住、显式点播和模式阻塞有明确的停止路径；普通工作更新保留飞行画面，结束后恢复最新状态，过期计时回调不会续飞。
- Q 弹和拉伸使用独立 CSS scale/rotate，不覆盖原来的朝向/移动 transform；撞墙沿碰撞轴挤压，落地沿竖轴挤压。

原生拖拽仍是 Clawd 的跟手拖动，本次没有换成 DSH 的弹簧跟随引擎；碰撞范围按用户选择限定到屏幕四边。

## 点击音效与开关

1.5.3 起改用 dsh-pet 原版 `click-duck.wav` 点击音效，按原字节复制，约 345 ms；经 Clawd 原有播放链路播放，音量为应用主音量的 50%，尊重全局静音、音量和免打扰，100 ms 内连点最多触发一次。1.5.0–1.5.2 使用的本仓库合成短音已替换，详见 [音效核查与来源](clawd-audio.md)。

主题扩展：

```json
"petInteractions": { "enabled": true, "clickSound": true }
```

`enabled: false` 关闭本次扩展；`clickSound: false` 只关闭轻音效。修改主题后重新安装主题并重启。其他未启用此字段的主题不增加长按/弹弓手势。

## 1.5.1 偶发甩不出去的修复

本次计划：先用原版完整输入处理器复现事件顺序、坐标和短促甩动问题；修复并补回归；更新本机应用、文档及 GitHub。

已复现的问题与处理：

1. 松手前先收到 `buttons === 0` 的移动事件，原实现会取消甩抛。现在将其作为物理松手结算一次，后续 `pointerup` 不再重复触发；失焦、系统取消、丢失捕获仍只取消。
2. 窗口跟着鼠标移动时，`clientX/Y` 可能几乎不变。拖动阈值与朝向改用屏幕坐标，松手携带原始轨迹，避免主进程取样或动画帧延迟漏掉最后一下。
3. 原来的 150 ms 全段平均会稀释最后的加速，而且小于 20 ms 直接忽略。现在采用最后 60 ms，保留原来的慢放死区与速度上限；慢慢放下或甩后停住仍不飞。
4. AI 工作原来会直接阻止甩抛。现在用户的主动甩抛可覆盖临时画面，任务数据正常更新，飞行结束恢复最新状态；挠痒、受惊的空闲条件保持不变。

74 项 Node 测试和 5 项 Python 测试全部通过。已构建并更新本机动画版，核对安装包 5 个脚本语法、安装模块与源码一致、签名检查通过。原生菜单可正常打开，关闭后恢复真实工作画面；界面工具主要选中透明输入窗口，未能人工确认完整甩抛轨迹。真实鼠标手感仍需要用户按日常操作体验，自动化回归不能代替这一点。

原版应用保留；1.5.1 更新前的动画版和主题备份于用户数据目录 `app-backups/throw-v151-20261029-160415/`；1.5.0 更新前备份仍在 `app-backups/physics-20261029-153934/`。上游交互设计和物理参数参考 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，现有动画及许可不变。
