# 5 小时余额阈值动画

## 需求与执行计划

按实际 5 小时**剩余额度**下降跨过阈值自动播放，不需要鼠标点击。计划并完成：核对现有额度模型和六个素材、实现阈值监听与交互避让、补充边界测试、更新本机动画版、提交代码。

| 剩余额度下降到 | 动画 |
| --- | --- |
| 95% | 钱袋满溢 |
| 80% | 金袋叮当 |
| 70% | 钱袋如常 |
| 50% | 数金皱眉 |
| 25% | 袋空如洗 |
| 5% | 分文不剩 |

只在上一次剩余值高于阈值、这一次小于或等于阈值时触发。重复报告同一值不重复播放；一次更新跨过多个阈值，只播放最低的那个。首次读取作为基线，启动时不补播历史阈值。余额回升后可以再次下降触发。重启应用重新建立基线。

## 数据与交互

复用 Clawd 内存中的 `buildSessionSnapshot().accountQuota`，支持 Claude、Codex、Codex Spark、Kimi、Antigravity，各来源和额度族分别记录。`remaining = 100 - usedPercent`，优先核实 `windowMinutes === 300`；明确报告其他时长时不使用，即使字段名叫 FiveHour。旧数据未报告时长时才按 FiveHour 字段兼容。

每秒检查一次；实际触发速度取决于对应服务向 Clawd 上报新额度的速度。此功能不主动请求服务、不读取密钥、不伪造额度。窗口已过期或没有数据时不播放，也不把过期视为恢复满额。

菜单打开、拖拽、迷你模式、免打扰或已有完整点播时延后播放；同一来源排队期间跨过新档会保留最新档，恢复额度则清除旧提醒。自动动画通过现有完整播放器播放约 10.04 秒，然后恢复最新任务显示。工作期间也能触发，不修改实际任务状态；用户拖拽可接管。

保留右键 `查看5小时余额`：列出服务剩余百分比、上次确认时间，并可手动播放当前档动画。手动查看使用连续区间（≥95、≥80、≥70、≥50、≥25、<25）；这和自动提醒的“跨越阈值事件”是两种用途。≤5% 标注“即将用尽”。没有额度数据时显示暂无数据。

本机右键菜单已确认显示真实 Codex 5 小时剩余数据。自动跨档通过模拟快照测试，未修改真实账户额度制造触发。安装包签名和 ASAR 补丁一致性另做检查。
