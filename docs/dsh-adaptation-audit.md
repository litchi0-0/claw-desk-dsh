# dsh-pet 适配差异核查

核查日期：2026-10-29。上游固定到 `4c892ecdf0401ecdafa52d6a7624bd118413ec2c`；本地以主题 1.3.1、提交 `4b5e9fa` 的适配代码为准。此次仅检查、补文档，不自动增加新功能。

## 核查方法与计划

1. 获取上游 Git tree 与功能说明，固定版本避免 main 后续变化影响结论。
2. 按文件名和 Git blob SHA 比较动画目录；检查本地主题绑定、补丁及集成代码。
3. 区分已导入素材、已绑定行为、Clawd 自有能力与未迁移逻辑；给出优先顺序并提交。

## 应保留的定制规则

- 没有工作就计入待机，鼠标活动不重置；这是用户明确要求，不应为了对齐上游改回鼠标静止判断。
- 本地余额按**剩余值向下跨阈值**触发，首次启动只建立基线；上游说明是按已用量分六档、周期查询，默认 1800 秒并启动查询一次。两者刻意不同，不属于漏适配。
- 上游内置余额服务商与 Clawd 当前支持的服务商不同，不能仅搬素材就宣称拥有相同的主动查询能力。
- 通知、置顶、缩放、任务 Dashboard 等应优先复用 Clawd 已有能力；本次没有逐项实测所有宿主功能，不能把它们一概列为缺失或已经验证。

## 建议顺序

1. **补自动动作池与调度**：让已导入的更多日常/玩耍动作真正自动出现，按分类和权重配置，工作/点击/拖拽/额度仍各走专用触发；不要简单把工作和余额动画混入随机池。
2. **补头顶信息气泡**：先显示额度百分比/恢复时间，再显示工作中的具体动作，保留真实数据和时效标识。
3. **补更多点击手势和可选音效**：挠痒/受惊素材需要明确定义手势与优先级，避免破坏双击与拖拽。
4. **补甩抛物理**：改动涉及窗口位置、屏幕边界和显示缩放，需单独实施与运行验证。
5. **聊天、人设、语音、多宠物**：属于新增子系统，应按需要分别做，不能当成一项素材绑定完成。
