## 播放与来源

- 所有 106 项均可点播，包括工作状态、额度展示与说话动画。这些只是画面，不会伪造真实余额或执行聊天接口。
- 保留原来的 20 种自动待机动作；全量目录用于手动选择。
- 保留从画面加载成功回执起计时的完整播放、手动停止与恢复最新状态。
- catalog.json 记录每段的中文名、层级、预览文件、透明源文件和 Git blob SHA-1；sources.json 记录源 SHA-256、输出 SHA-256、帧数和完整时长。
- 36 个原有动画在新提交中源内容未变，按 Git blob 校验复用；其余 70 个新增。部分源文件从同一提交的 jsDelivr 镜像下载，再与 Git tree 的 blob 哈希校验。
- 共 15,929 帧；已逐帧检查透明背景和有效动画内容，逐文件检查完整时长与输出哈希，并目视检查全量拼图。部分源特效有淡出或延伸至画布边缘，保留源素材表现。

1.3.0 帧率更新：上述 15,929 帧为旧 15 FPS 产物记录。当前重新生成自 25,423 个源采样帧，WebP 合并重复画面后实际保存 24,273 帧，全部按 24 FPS 时间轴播放，静止画面的停留时间没有缩短。
