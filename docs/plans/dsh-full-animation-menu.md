# DSH 全量动画与分层菜单计划

目标：接入用户指定 preview 目录中全部 106 项对应的透明源动画，并按用途分层点播，保持完整播放。

1. 核对最新 Git tree、预览命名映射和透明 WebM 源，固定到提交；生成 catalog.json，每项记录中文名、分类、预览路径与 Git blob 校验值。
2. 扩展增量生成脚本，复用 36 个已有转换，下载和校验剩余素材，生成完整片长与手动动作清单。自动待机仍保留现有 20 项。
3. 先更新菜单测试，检查分层、完整覆盖、每项只出现一次，以及停止入口；再将中文菜单改为读取主题分类。
4. 检查所有素材的透明度、帧数、时长、哈希与主题加载；目视检查新增素材拼图。
5. 备份本地动画版及主题，安装并检查实际菜单，更新文档，完成一次 Git 提交。
